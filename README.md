# BySide 咫尺

让相隔千里的家人，聚到同一张桌上。

介绍页：https://doris112233.github.io/byside/

## 这是什么

两台可交互投影，连接两张异地的桌子，让家人的陪伴回到老人身边。
老人和孙辈可以在各自家中的桌面上，看见对方的动作与操作，共同游戏、创作和分享。

异地家庭大多靠电话和视频维系感情。看见彼此是一种陪伴，我们想探索的是屏幕之外的另一种可能：
一起"在场"的感觉。不是再造一块屏幕，而是让"一起做事"重新发生在真实的桌子上，
真的棋子、真的笔、真的毛线，用手去碰、去移动、去完成。虚拟的部分只做一件事，
把这份真实原样递到千里之外的另一张桌子上。

老人不需要学习任何新软件，像平时一样摆棋、画画、做手工，投影和摄像头在背后完成识别与同步。
家人随时接入，看见并回应老人此刻正在做的事，把"通话时间"变成"共处时间"。

连上之后，两张桌面变成同一个空间。会被同步过去的是：手势与触摸位置、棋子与实体物品、
绘画与书写轨迹、手工制作过程、语音与影像。

能一起做的事：远程下棋、隔空拼图、家庭小游戏；共同画画、一起做手工、各自完成一部分再合成一件作品；
把桌上的手工、老照片、养的花、做的菜分享给家人。下棋是第一个做实的场景，用来验证"一起做事"这个核心机制真的成立。

## 怎么做到的

每一端是一台摄像头、一台投影仪和一块小电脑。桌面上移动的每一颗棋子，被摄像头识别为坐标，
经网络转发，由对面的投影在同一坐标上还原。被传递的是位置，不是画面。

- 识别：Python + OpenCV。每个格点比较内圆和外环的亮度中位数来判断有没有棋子、什么颜色；
  每端只认自己那一色，对方的子投成空心环，摄像头不会把它当成真棋子再传回去
- 标定：投影仪在棋盘四角打出 ArUco 标记，摄像头认出后自动算出棋盘在画面里的位置，不用手动对
- 同步：Node 写的 WebSocket 中继，传坐标、邀请和在线状态，带序号和断线补发
- 音视频：声网，token 由中继签发
- 桌面界面：一个网页，投影到桌上用遥控器操作。起名、加好友、呼叫、通话里下棋或折纸
- 硬件：电脑加影石摄像头，或 RDK X5 板子，跑的是同一份代码
